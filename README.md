미디어 감사는 삭제하지 않고 `?operator=media#media-audit`로만 접근하는 운영자용 읽기 전용 화면으로 분리했다. 일반 방문자는 기록보관소의 간결한 출처 안내와 `MEDIA_CREDITS.md`를 통해 공개 원칙을 확인한다. 자산 대장과 권리 검토 상태, 참고 전용 ZIP 차단 규칙은 그대로 유지된다.

새 문양은 기존 핵심 상징을 보존하되 조직의 실제 기능에 맞게 단순화했다. U.A.C는 이중 격리환과 네 접근축, N.H.C는 방어축과 네 현장 판단, F.H.C는 기업 연구틀과 자산 렌즈, Ash Crew 계열은 인식표·회수틀·민간 분기선을 중심으로 재구성했다. 모든 구형 WebP는 삭제하지 않고 감식 계보와 로드 실패 대체 자산으로 남겼다.

5.37.0은 정보 분석실의 세력 표식을 단순 장식 이미지에서 출처와 신뢰도를 가진 감식 자료로 전환했다. 기존 11개 세력을 하나의 문양 등록부에 연결하고, S.I.D·S.O.N·우시노다교·P.O.H의 표식을 작은 지도 노드에서도 읽을 수 있는 SVG 마스터로 다시 제작했다.

세력 상세에는 문양의 분류, 확인 근거, 최초 확인 시점, 신뢰도, 사용처와 구성 요소 해석이 표시된다. S.O.N 표식은 중앙조직의 공식 휘장이 아닌 분산 연합의 공통형으로, P.O.H 표식은 조직 로고가 아닌 비공식 운송 코드로 구분했다. 우시노다 문양은 교단의 공식 승인 여부를 확정하지 않고 세 종파 파생을 위한 감식 재구성으로 남겼다. SVG 로드가 실패하면 기존 WebP를 사용하고, 두 자산이 모두 실패해도 세력 약자 표식으로 열람을 유지한다.

5.36.2는 세계사 32개 사건을 하나의 설명자 문체에서 실제 기록 조각의 집합으로 다시 작성했다. 각 사건에는 작성자, 수신자, 작성 목적과 `공식 연표`, `현장 보고`, `사후 검토`, `증언 발췌`, `감청 기록`, `감식 보고`, `후대 분석`, `상충 기록` 가운데 하나의 문서 성격이 붙는다. 상세 화면은 일반 문장, 현장 로그, 증언과 편집 주석을 서로 다른 형식으로 표시한다.

새 본문은 모든 사건을 같은 3문단으로 정리하지 않는다. 기관이 당시 알 수 없었던 상대의 의도를 단정하지 않고, 숫자는 작전·증거·판정에 필요한 경우만 남겼다. U.A.C·N.H.C·S.I.D·F.H.C와 현지 공동체의 어휘와 보고 목적도 분리했다. `WRITING_STYLE_GUIDE.md`는 이 기준과 반복 표현 점검, 실제 역사 처리 원칙을 다음 설정 작업의 공통 규칙으로 고정한다.

1995년 도쿄 기록은 공개된 실제 공격의 실행 주체와 피해 사실을 그대로 존중한다. Project Curse의 N.H.C 작전은 같은 날 다른 구역에서 위조 신호를 추적한 별도 기록으로 분리했으며, 두 사건의 직접적인 인과관계는 정사에 등록하지 않는다.

5.36.1은 2006년에서 멈춰 있던 세계사를 2030년까지 확장했다. 2007년 북미 지휘망 철수와 2008년 데드 존 지정, 2012년 대흑림 측량 소실, 2014년 성채 피난권, 2018년 북부전선 개전, 2021년 F.H.C 서브매서커, 2030년 `OP-BROKEN-CROWN` 개시까지 14개 가상 사건을 추가했다. 세계 기록은 이제 8개 시대·32개 사건을 제공한다.

새 사건은 단순한 연도 목록이 아니라 발생 원인, 기관 대응과 장기적 결과를 구분해 작성했다. 각 사건에는 판정 등급·근거·자료 상태가 붙으며, 확정되지 않은 지휘계통이나 책임 주체는 추정 또는 상충 기록으로 남는다. 기존 지도·작전·순례 시나리오의 북부전선, 검문소 07과 남부 동원 사건도 새 연표 ID와 절대연도에 연결했다.

2007–2030 연표는 Project Curse 내부에서 창작한 가상 역사다. 실제 역사 결합 원칙과 참고 이미지 비편입 정책은 그대로 유지하며, 실제 참사의 원인이나 피해자를 가상 사건으로 대체하지 않는다.

5.36은 세계 사건 연표를 단일 사건 목록에서 다섯 시대의 정사 복구 장부로 개편했다. 기존 18개 사건 본문은 유지하면서 각 사건에 `확정 기록`, `복수 기록 일치`, `현장 관측`, `증언 기반`, `상충 기록`, `정보 추정` 판정을 붙이고 판정 근거와 자료 상태를 분리해 표시한다.

세계 기록 상단에서는 시대별 사건을 필터링하고 복구 사건·시대 구획·확정 기록·정사 공백 수를 확인할 수 있다. 상세 기록은 해당 시대, 정사 판정, 출처 상태와 판단 근거를 본문보다 먼저 제시한다. 5.36 당시에는 일본의 기술 도약, 2006년 이후 절대연도, 남부 지리, 혈교 계통과 괴이 기원을 결정 대기 대장에 등록했다.

실제 역사와 연결되는 새 기록은 공개 역사, 비공개 작전 기록과 후대 분석을 구분한다. 실제 사건의 확인된 원인·책임·피해를 초상현상으로 대체하지 않으며, 같은 시각 주변의 누락 신호·봉인 기록·병행 작전으로만 세계관을 확장한다. 참고용 ZIP 이미지는 공식 설정이나 공개 자산으로 편입하지 않는다.

5.35는 기록보관소를 영상·문서의 단순 행 목록에서 분류형 신호 라이브러리로 개편했다. 공개 기록 13개는 사건·권역·규정·작전·개체·교단 분류와 위험도, 날짜, 관련 표식, 열람 형식을 카드에서 바로 확인할 수 있다. 분류 필터와 통합 검색은 같은 색인에서 함께 동작하며 모바일에서는 가로로 축약된 기록 카드로 전환된다.

이미지 카드는 `원본 보존`, `복원 추정본`, `출처 대조 대기`를 명시해 시각 자료가 실제 원본인지 재구성 장면인지 구분한다. 확인 가능한 이미지가 없는 기록은 임의 이미지를 채우지 않고 신호판으로 표시한다. 분류 전환음, 카드 장착 응답, 순차 진입 연출을 추가하되 기록을 열 때는 기존 영상·문서 음향과 중복되지 않도록 유지했다.

5.34는 다섯 채널의 이동을 단순한 화면 교체가 아니라 제어권 해제, 채널 획득, 화면 조립의 세 단계로 다시 구성했다. 단말·관제·연대기·정보망·보관소는 서로 다른 전환 문양과 퇴장·진입 움직임을 사용하며, 대상 화면은 채널 표식부터 핵심 정보와 세부 카드까지 중요도 순으로 조립된다. 전환 중 빠르게 다른 메뉴를 선택하면 마지막 요청을 안전하게 이어 받고, 같은 요청의 중복 실행과 효과음 중첩은 억제한다.

첫 기동은 약 9.5초, 같은 탭의 세션 복원은 약 5.9초, 기록 복귀는 약 5초 동안 연결·색인·검증·접근 단계를 차례로 표시한다. 100% 직후에는 접근 승인 상태를 별도로 유지한 뒤 단말을 공개해 로딩이 갑자기 끊기는 느낌을 줄였다. 메뉴 열기·닫기·선택음은 서로 다른 접점 계열로 분리하고 채널 전환음보다 낮게 조정했다.

5.33은 설정 패널의 정보 순서를 다시 설계했다. 패널을 열면 기술 수치보다 `자동 최적화됨`, `균형 모드 적용됨`, `데이터 절약 중`, `오프라인 열람 중` 같은 현재 상태가 먼저 보인다. 설정은 `화면·전송`과 `음향`으로 나뉘며, 연결·성능 원자료는 기본적으로 접힌 `고급 세션 진단`에서 필요할 때만 확인한다.

고급 진단은 부팅·DOM·전송·화면 전환뿐 아니라 현재 세션의 실제 표시 시간과 지원 브라우저의 JavaScript 힙 사용량을 함께 표시한다. 모바일에서는 설정 본문만 스크롤되고 닫기·완료 조작은 항상 화면에 남는다. 숨겨진 오프라인 복구 레이어가 포인터 입력을 가로막던 문제도 함께 수정했다.

5.32는 브라우저의 데이터 절약 설정, 연결 유형·지연·대역폭, 메모리와 CPU 스레드를 하나의 전송 정책으로 결합한다. AUTO는 환경에 따라 FULL·BALANCED·CONSTRAINED를 선택하고, 사용자는 표시·음향 설정에서 DATA SAVE 또는 HIGH를 직접 고정할 수 있다. 제한 모드에서는 다음 화면 이미지 준비, 대용량 환경음, 영상 선로딩과 고비용 지도 효과를 억제하되 채널 전환의 기본 호흡과 기록 열람 기능은 유지한다.

연결이 끊기면 현재 열린 기록과 브라우저에 저장된 시나리오 진행을 유지하고, 하단 복구 패널에서 상태를 확인하거나 시각 자료를 다시 요청할 수 있다. 현재 판정 등급과 그 근거는 설정 패널의 `ADAPTIVE DELIVERY POLICY`에 표시된다.

상단 다섯 공개 채널은 저장된 진행 상태를 직접 요약한다. 단말은 현재 수신 신호, 전장·권역은 진행 중인 작전·순례, 세계 역사는 연결 사건, 세력 정보는 세력 파일, 기록보관소는 읽지 않은 판정 또는 공개 기록 수를 표시한다. 작전 판단, 순례 진행, 판정 문서 읽음 상태가 바뀌면 메뉴 배지와 화면 헤더 계기가 같은 이벤트에서 갱신된다. 미디어 감사 수치는 운영자 전용 화면에서만 확인한다.

설정 패널의 `LIVE SESSION TELEMETRY`는 부팅 화면 실제 노출 시간, DOM 준비 시간, 현재 세션 전송량, 마지막 채널 전환 시간과 CLS를 로컬에서 측정한다. 공개 5.30 기준 최초 화면은 약 8.69초 노출, 전환은 0.81–0.84초, CLS 0으로 확인했다. 초기 4.49MB 중 3.09MB를 차지하던 환경음은 첫 사용자 입력 전에는 요청하지 않도록 바꿨으며 부팅 연출 길이 자체는 유지했다. 공개 5.31 콜드 세션은 첫 입력 전 약 665KB로 확인되어 기존 기준보다 약 85% 줄었고, 환경음은 첫 입력 뒤에만 한 번 요청되었다.

다섯 화면은 이제 같은 메뉴의 내용 교체가 아니라 서로 다른 폐쇄 서버 채널로 보인다. 단말은 적색 명령 노드, 지도는 청록색 좌표 관제, 연대기는 황동색 시간축, 세력 분석은 청색 정보망, 보관소는 적색 이중 봉인 체계를 사용한다. 공통 정체성 헤더는 각 화면 런타임이 내용을 다시 그린 뒤에도 복원되며, 진입 시 화면 용도에 맞는 표식·계기·정보 등장 연출이 이어진다.

상단 빠른 이동 메뉴에는 홈을 포함한 다섯 공개 채널의 번호·명칭·영문 코드가 표시된다. 모바일에서는 한 열의 채널 선택 패널로 전환되고 현재 화면 표식이 유지된다. `DISPLAY / FX` 설정에서는 시각 효과 강도, 인터페이스 음향, 환경음, 텍스트 등장 연출을 각각 조절할 수 있으며 선택값은 현재 브라우저에 저장된다. 운영체제에서 동작 줄이기를 켠 경우에는 저장값을 지우지 않고 REDUCED 연출을 우선 적용한다.

관제 화면을 중심으로 홈 대시보드와 상단 빠른 이동 메뉴를 다시 구성했다.
화면·버전 명칭은 `build-info.js`, 화면 이동은 `app-shell.js`가 각각 단일 기준으로 관리한다.

내부 문서와 영상형 기록의 이미지에는 시각 증거 등급을 표시한다. 문서별 보관소 패널에서 원본 계열, 열람 보정본, 복원 추정본과 출처 대조 대기 자산을 분리하고, 실제로 연결된 사본만 전체 화면 비교 슬라이더로 대조한다. 대흑림·데드존 복원 이미지는 원본이 등록되지 않았음을 명시하며 실제 원본이 추가되기 전에는 원본 기록으로 취급하지 않는다.

용량이 큰 PNG·JPEG 원본 20개는 수정하지 않고 보존한다. 일반 문서와 영상 기록에서는 480px·최대 960px WebP 파생본 40개를 화면 폭에 맞춰 선택하고, 전체 화면 증거 뷰어를 열 때만 보존 원본을 요청한다. 이미지 요청·디코딩·실패 상태는 기록 복구 연출로 표시하며 원본 비교 슬라이더는 양쪽 프레임 준비가 끝난 뒤에만 활성화된다. 다음 영상 장면과 이동 대상 화면의 대표 이미지는 짧은 전환 구간에 미리 준비하고, 데이터 절약·저속 연결·모션 감소 환경에서는 더 가벼운 정책을 사용한다.

공통 사건 레지스트리가 연표·상황 관제·정보 분석·기록보관소를 연결한다. 지도에서 사건을 선택하면 관련 연표, 세력 파일, 원본 기록과 작전 경로로 이동할 수 있으며 남부 집단 소환 차단 작전은 단계별 신호·명령 충돌·철수 경로를 한 화면에서 복원한다. 순례·동원 경로는 별도 지도 계층으로 켜고 끌 수 있다.

권역 관제도는 세계·권역·세부 구역·사건 지점의 네 단계로 확장했다. 대흑림은 서부 순례 회랑, 남방 해안 동원권, 내부 피난 성채권으로, 데드존은 서부 귀환 회랑, 고대 왕국 묘역, 내륙 무응답권으로 나뉜다. 42개 지점에서 관련 기록과 작전으로 바로 이동할 수 있고, 남방 해안과 데드존 교환점은 저장된 `OP-BROKEN-CROWN` 판단에 따라 상태와 표식이 바뀐다.

세부 지점을 선택하면 연결된 경로와 지점만 강조되고 나머지 정보는 감쇠된다. 각 지도에서 경로, 위험 반경, 통신권, 공간 왜곡 레이어를 독립적으로 전환할 수 있으며 연결 경로 패널은 현재 지점의 이전·현재·다음 단계, 위험도, 신호 상태와 적용 순례 규칙을 함께 표시한다.

대흑림 서부 회랑의 `불빛 없는 성채`는 첫 번째 직접 진행형 순례 시나리오다. 여섯 현장에서 규칙을 지키거나 위반하는 판단을 내리면 공포도, 오염도, 통신 신호와 세 가지 결말이 달라진다. 진행과 결과는 브라우저에 저장되며 세계 지도, 세부 권역, 작전지도와 홈 수신 목록에 즉시 반영된다.

데드존 `서부 귀환 회랑`은 두 번째 직접 진행형 시나리오다. 네 귀환자와 다섯 번째 생체 신호를 여섯 검문 단계에서 분리하며, 신원 일치율·노출도·기억 정합성·판단 신뢰도와 네 가지 귀환 판정을 별도 저장한다. 검문 결과는 서부 귀환 지점, 검문소 07, 전용 작전지도와 홈의 귀환 신호에 동기화된다.

`역방향 순례` 결말에서 복호화되는 `DZ-VR-04`는 세 번째 시나리오인 `검문소 아래의 구조 신호`를 연다. 회수팀은 검문소 지하의 여섯 좌표에서 물리 견인선, 팀 생존도, 심도와 메아리 오염을 관리하고 원신호를 회수하거나 봉쇄하거나 새로운 중계자가 되는 결말을 맞는다. 잠금 전에도 작전지도에서 봉인된 경로와 해금 조건을 확인할 수 있다.

세 시나리오는 이제 앞선 선택을 단순 수치로만 저장하지 않는다. 거절한 의뢰, 추적한 신호, 소각한 회분, 공개한 지도와 회수 과정의 판단이 이후 현장의 서술·신호·선택 문구와 일부 결말을 바꾼다. 선택 직후에는 판정과 계기 변화가 짧은 현장 기록 화면으로 봉인되며, 같은 결과가 작전지도 단계 상태와 홈 수신 신호에도 이어진다.

세 시나리오의 열 결말에는 조건부 현장 판정 기록이 연결된다. 직접 확인한 결말만 기록보관소에서 복호화되며, 당시 선택 여섯 개와 최종 측정값을 별도 사본으로 저장한다. 현재 시나리오를 초기화해도 해금 기록은 유지되고, 읽지 않은 판정 문서는 메인 단말과 보관소에 알림으로 표시된다. 판정 보관소의 읽음 상태, 대흑림 기록, 데드존 귀환 기록, 전진 회수 기록과 전체 기록은 서로 다른 범위로 초기화할 수 있다.

대흑림·데드존 설정글과 세 시나리오는 한국어 어순에 맞춰 다시 다듬었다. 시스템 안내는 짧은 설명문, 순례자 규칙은 직접적인 명령문, 선택지는 행동과 예상 위험이 바로 드러나는 문장으로 구분했다. 영문 코드는 분위기와 식별을 맡고 한국어 문장은 실제 의미를 전달한다.

보관소에는 대흑림, 데드존, 순례자의 규칙과 `OP-BROKEN-CROWN`을 추가해 공개 기록을 13개로 확장했다. 작전 시나리오는 세 개의 상충 정보 경로를 직접 열어 임시 결론을 복구하며, 지역 사진 두 장은 원본과 혼동되지 않도록 `복원 추정본`으로 표기하고 별도 출처 대장에 등록했다.

대흑림 기록은 녹색 유기 신호와 내부 거리 오차 계기판을, 데드존 기록은 탈색된 위성 회신과 귀환 검문 계기판을 사용하는 별도 권역 테마로 분리했다. 홈 단말은 기록·작전·사건 데이터에서 공개 기록 수, 활성 작전, 미해결 신호와 최근 수신을 계산하며 각 신호에서 관련 작전·기록으로 직접 진입한다.

오디오는 단말 접점·지도 스캔·연표 페이지·정보 교신·보관소 장착·작전 단계·지역 이상 신호로 의미를 분리했다. 다섯 화면과 대흑림·데드존·규칙·시나리오 문서가 각자 다른 음향 프로필을 사용하며, 경보와 기록 장착 시 환경음을 잠시 낮추는 덕킹과 버스별 중첩 제한을 적용한다.

영상 기록 전용 BGM과 라디오 정적 레이어는 영상 기록이 실제로 열려 있을 때만 재생된다. 기록을 뒤로 나가거나 다른 화면으로 이동하면 전용 음원과 이전 화면의 효과음 버스를 즉시 종료해 일반 지도·메뉴로 소리가 넘어오지 않게 한다.

`OP-BROKEN-CROWN`은 정보 경로 회수, 임시 지휘 판단과 현재 지도 단계를 브라우저에 저장한다. 처형·생포·공동 대응·판단 보류 결과에 따라 작전 지도의 경로, 시설 상태, 6단계 판정과 홈 경보가 함께 변경되며 새로고침 뒤에도 작전을 재개할 수 있다.

정적 PC·모바일 기록 단말 패키지다. 루트의 `index.html`을 열거나 폴더 전체를 GitHub Pages에 배포한다.

## 현재 화면

- 단말 상태
- 상황 관제
- 세계 기록
- 정보 분석
- 기록보관소

과거의 분리된 지도 페이지를 복원하는 대신, 지역 상황도·세부 권역·작전 경로를 한 화면에 합친 `권역 관제도`를 사용한다. 예전 주소 `#region-map`, `#zone-map`, `#operation-map`은 새 관제도로, `#faction-relation`은 세력 분석실로 연결된다.

기록보관소는 `종교`, `불멸을 향해`, `괴이`, `사쿠마의 테이프`를 영상 기록으로,
나머지 공개 기록을 문서 파일로 분리한다. 허브에서 화면을 선택하면 공통 클릭음을 반복하는 대신,
각 채널의 용도에 맞는 짧은 접점·스캔·페이지·교신·장착 신호를 재생한다.

이번 정리에서 참조되지 않는 원본 음원 2개와 이미지 5개, 폐기 화면 전용 안내 문서를 제거했다. 보호 기록인 `종교`와 `불멸을 향해`의 인라인·독립 페이지는 해시로 보존한다.

영상 기록은 공통 재생 엔진 하나와 기록별 설정 모듈 네 개로 분리했다. 종교·불멸을 향해·괴이·사쿠마의 테이프는 각자 영상, 배경음, 전환음과 페이지 공급 정보를 소유하며 `record-cinematic-runtime.js`는 등록된 설정을 조회해 재생만 담당한다.

PC와 모바일은 같은 화면 구조를 사용한다. 주소 해시가 없으면 `단말 상태`로 진입하고,
홈 대시보드와 상단 빠른 이동 메뉴에서 상황 관제·세계 기록·정보 분석·기록보관소로 이동한다.
각 화면 상단의 `단말 메뉴`로 허브에 복귀한다. 문서 페이지에서 돌아오는
`?return=archive`만 기록보관소를 복원한다. 사이드 메뉴가 사라진 공간은 연표·세력 카드·
기록 색인이 더 넓게 사용하고, 긴 본문은 읽기 폭을 유지한다.

첫 방문에는 약 9.5초의 전체 기동이, 같은 탭의 재방문에는 약 5.9초의 `SESSION RESTORE`가
표시된다. 기록보관소 복귀도 약 5초 동안 채널을 안전하게 분리하며, 빌드가 바뀌면 첫 진입에서
전체 기동을 한 번 새로 보여 준다. 모션 감소 설정에서는 움직임을 줄인 약 3.8초의 단순 연결 화면을 유지한다. 화면 이동은
현재 화면 퇴장, 채널 전환, 대상 화면 정착·조립의 세 단계로 진행한다. 오디오
버튼은 로컬 환경음과 의미 기반 효과음의 음소거 상태를 브라우저에 저장한다. 원본·보정본·복원 추정본의 구분은
`ASSET_POLICY.md`와 `assets/resources/ASSET_REGISTRY.md`를 따른다.

## 공개 배포 전 확인

포함된 음원과 영상은 파일명만으로 공개 재배포 허가를 판단할 수 없다. GitHub Pages 공개 전 원본 출처, 라이선스, 출처 표기와 재배포 허용 범위를 확인한다.
