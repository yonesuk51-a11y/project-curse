# Project Curse V6 인물 기록 규약

문서 상태: `PEOPLE A01 / LEGACY INTAKE / NOT YET CANON`

## 1. 채널 역할

`#/people`은 주인공 명단이 아니라 구 명부에 남은 사람을 다시 판독하는 채널이다. 프레이를 중심에 복구하지 않으며, 기존 56명은 모두 동일한 `UNREVIEWED` 상태에서 시작한다.

이 채널은 세 층을 구분한다.

1. `LEGACY REGISTER / PRESERVED` — 초기 명부의 이름·소속·직책·능력·장비·사망 표기.
2. `SUPPLEMENTAL IDENTITY / PROVISIONAL` — 후대에 보완한 전체 이름·생년·성별·출신·경력·욕망·두려움.
3. `CHARACTER TRACKING / V6` — V6 사건과의 연결 판정. 현재 A01에서는 모든 인물이 `NO ADOPTED INCIDENT LINK`다.

## 2. 현재 상태 원칙

구 명부의 `active`는 2006년 전후 활동 기재일 뿐이다. 다음과 같이 표시한다.

| 구 명부 상태 | V6 표시 | 2042 판정 |
|---|---|---|
| `active` | `2006년 활동 기재` | `UNRESOLVED` |
| `deceased` | `사망 기재` | 사망 시점·원인·회수 여부 별도 판정 |
| `unknown` | `2006년 당시 상태 미확인` | `UNRESOLVED` |

인물의 이름이 있고 능력이 강해도 생존 보정을 부여하지 않는다. 2042년 현재 생존을 확인하려면 해당 인물을 직접 식별할 수 있는 사건 기록이 별도로 필요하다.

## 3. 관계 경계

- 사쿠마 유타와 레드 마우스는 원 명부에서 직접 연결된 동일 인물 표기를 유지한다. 다만 F.H.C-아크, U.A.C 정보원, 하이먼 리더의 시간 순서는 확정하지 않는다.
- U.A.C 아론과 신디케이트 아론은 별도 파일로 유지한다.
- 브리안 알베로즈와 마테오 알베레즈는 이름 유사성만으로 연결하지 않는다.
- 야나미 신카와 야나미 미즈미는 같은 성씨만으로 혈연을 확정하지 않는다.
- 알마 가족망과 경호 관계는 잠정 보완층이며 V6 정식 가족계보가 아니다.
- 사도 번호는 명부 순서다. 힘·서열·지휘권 순위로 자동 해석하지 않는다.

## 4. 사건 추적 채택 조건

인물을 V6 사건선에 연결하려면 다음을 모두 기록한다.

1. 사건 ID와 인물 ID가 직접 대응하는 출처.
2. 사건 당시 역할과 소속 상태.
3. 참여·목격·지휘·피해·후대 분석 가운데 관계 유형.
4. 마지막 확인 시각 또는 확인할 수 없는 이유.
5. 생환·사망·실종·귀환 판정과 그 근거.
6. 다른 기록과 충돌하는 항목.

가족 비극, 잃어버린 스승, 기관의 상충 명령과 같은 중심 서사는 제안 단계일 뿐이다. 관련 인물을 먼저 정한 뒤 이야기에 맞추어 과거를 역산하지 않는다.

## 5. 능력 표기

능력 이름은 원 명부 보존층에 남긴다. 다음 항목이 없는 능력은 완성된 전투 규칙으로 취급하지 않는다.

- 발동 조건
- 거리와 범위
- 지속 시간
- 사용자에게 돌아오는 대가
- 차단·회피·오작동 조건

현재 명부에 이름만 있는 능력은 `CAPABILITY LABEL / MECHANICS UNRESOLVED` 상태다.

## 6. 접근성·검색

- 56명 모두 실제 버튼으로 선택한다.
- 이름·구 명부명·별칭·소속·역할·능력을 한 검색창에서 찾을 수 있다.
- 분류군, 사망 기재, 제한 기록, 능력 표기로 필터링할 수 있다.
- 선택 상태는 `aria-current`로 제공한다.
- 상세 파일 제목에 키보드 포커스를 이동할 수 있다.
- 모바일에서는 인물 목록을 제한 높이로 먼저 보여 주고, 상세 파일은 별도 중첩 스크롤 없이 이어서 읽는다.

## 7. 생성 스냅샷

`v6/assets/js/people-data.js`는 다음 세 자료의 명시적 스냅샷이다.

- `assets/js/data/personnel-data.js`
- `assets/js/data/personnel-profile-data.js`
- `PERSONNEL_SOURCE_NOTES.md`

`v6/tools/build-people-snapshot.mjs`로 재생성한다. 구판 자료가 바뀌어도 스냅샷을 갱신하고 V6 채택 판정을 다시 확인하기 전에는 자동으로 정사가 바뀌지 않는다.

## 8. 다음 채택 단계

A02에서는 모든 56명을 한꺼번에 사건에 배치하지 않는다. 직접 근거가 있는 인물부터 소수씩 채택한다.

1. 사쿠마 유타의 복수 신분과 기록 시간 순서 판정.
2. 우시노다 10사도의 상호 경쟁 교리와 독립 목적 작성.
3. 기관 지휘부와 현장요원의 명령 충돌 기록.
4. 민간 인물과 가족 관계의 실제 사건 접점 검증.

채택되지 않은 인물도 삭제하지 않는다. `UNREVIEWED`, `DISPUTED`, `NO INCIDENT LINK` 상태 자체가 기록의 일부다.
