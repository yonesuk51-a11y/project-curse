# Project Curse V6 세력 재창설안

문서 상태: `DRAFT / CORE NAMES A02 / LINEAGES PARTIALLY RESOLVED`

`A02 ADOPTED NAME / V6 DRAFT`는 이번 리메이크 화면에서 사용할 기준 명칭을 채택했다는 뜻이지, 사용자 최종 정사 승인을 대신하지 않는다. 명칭의 판정과 표식의 출처 판정은 별도 축으로 기록한다.

## 1. 공통 원칙

V6의 세력은 선악 진영이 아니라 `어떤 손실을 누구에게 떠넘기는가`로 구분한다.

각 세력 문서는 다음 여섯 질문에 답해야 한다.

1. 무엇을 지키는가
2. 누구를 구조 대상에서 제외하는가
3. 어떤 현상축을 주로 사용하거나 봉쇄하는가
4. 힘의 대가를 누가 지불하는가
5. 승리했을 때 세계가 어떻게 더 나빠지는가
6. 표식이 공식 휘장인지 현장 감식 재구성인지

## 2. 기관·기업·이탈 세력

### U.A.C — Unified Anomaly Compact / 통합 이상현상 협약체

- V6 역할: 국제 접근권, 기록 교환, 격리·철수 우선순위 조정
- 지키는 것: 국가 간 최소 협약과 공통 기록 형식
- 버리는 것: 공통 기준에 등록되지 않은 사람과 지역
- 수단: 접근 허가, 봉쇄 등급, 자료 소유권, 다기관 판정
- 대가 지불자: 회랑 밖 민간인과 승인되지 않은 귀환자
- 승리의 실패: 세계가 살아나는 대신 죽음을 더 정확히 배분하는 관료제가 완성된다.
- V6 명칭 상태: `OFFICIAL PROPOSAL` — 1993년 공개 협약명. 구판 `United Nations Anomaly Containment`는 `DEPRECATED`, `Urban Anomaly Containment / Urban Anomaly 봉쇄`는 검색용 레거시어로만 보존한다. 근거 없는 `Urban Anomaly Council`은 사용하지 않는다.
- 표식: 이중 격리환과 네 접근문 / `OFFICIAL DRAFT`

### N.H.C — Nonlinear Hazard Command / 비선형 위난사령부

- V6 역할: 현장 봉쇄, 전투, 구조 회랑 개방과 철수
- 지키는 것: 차단선 뒤 인구와 작전 가능한 병력
- 버리는 것: 회수 비용이 차단선 가치보다 큰 팀
- 수단: 대화력 무기, 생기 운용자, 중장비, 소모성 앵커
- 대가 지불자: 현장대와 등록되지 않은 잔류민
- 승리의 실패: 전선을 유지할수록 더 어린 병력과 더 넓은 징집권이 필요하다.
- V6 명칭 상태: `OFFICIAL PROPOSAL` — 1993년 정식 편제, 2001년 U.A.C 조정체계에서 독립
- 선행 약어: 1984–1986년의 `N.H.C` 표기는 대화력 장비 규격, 소규모 현장대 호출명, 후대 편집 라벨 가설이 상충한다. `Nonlinear Hazard Classification / 비선형 위난 분류규격`은 분석상 임시 풀이이며 당시 정식 조직명이나 후대 사령부와의 직접 연속성을 확정하지 않는다.
- 구판 대조명: `National Hazard Control` / `LEGACY / DEPRECATED`
- 표식: 수직 방어축과 열린 철수 회랑 / `OFFICIAL DRAFT`

### S.I.D — Signal Integrity Directorate / 신호무결성국

- V6 역할: 도시 비정합 수사, 신호 감식, 인물 동일성 추적
- 지키는 것: 공인 기록과 도시 회랑의 내부 정합성
- 버리는 것: 기록과 기억이 일치하지 않는 시민
- 수단: 감청, 미끼 신호, 인식표 대조, 비인가 구금
- 대가 지불자: 오탐지 대상과 내부 정보원
- 승리의 실패: 안전 도시는 모든 사람의 기억과 관계를 지속 감시하는 감옥이 된다.
- V6 명칭 상태: `OFFICIAL PROPOSAL` — 1993년 조사부 편제, 2001년 독립. `Special Investigation Department`는 1993–2001년 명칭 또는 지역 위장명으로만 남긴다.
- 표식: 어긋난 두 렌즈와 단일 증거점 / `OFFICIAL DRAFT`

### F.H.C — Frontier Habitat Consortium / 개척거주권 컨소시엄

- V6 역할: 비정합의 산업화, 인공 접속자·장비·표본 생산
- 지키는 것: 연구 계보, 특허, 시설과 지휘 가능한 실험체
- 버리는 것: 실패한 접속자와 외부 피해 지역
- 수단: 계약, 시설도시, 생체재료, 실험 기록 독점
- 대가 지불자: 실험체, 하청 현장대, 시설 주변 주민
- 승리의 실패: 인간 생존이 기업 소유 규격에 종속된다.
- V6 명칭 상태: `OFFICIAL PROPOSAL` — 1982년 아마리온 연구·자산 계보를 승계. `Foremost Hitech Cooperation`은 구판 홍보 번역으로만 보존한다.
- 지부 원칙: `F.H.C-Union`, `F.H.C-Ark`, `T.A.D`는 독립 세력이 아니라 부모 마크에 카르투슈를 붙이는 지부다. 2021년 이후 실제 명령권은 `DISPUTED`다.
- 표식: 육각 공정틀과 표본을 붙드는 조리개 / `OFFICIAL DRAFT`

### Amarion — 초기 공간 연구기업

- V6 역할: 1975년 전후 경로 비정합의 최초 산업 연구자
- 지키는 것: 현재는 조직보다 사라진 연구 계보
- 버리는 것: 실험 원인과 피해 책임을 증명할 자료
- 수단: 불가능 좌표, 반복 경로, 공간 장치
- 대가 지불자: 초기 시설 인원과 후대 연구자
- 승리의 실패: 이미 해산했더라도 규격은 모든 기관과 교단에 남는다.
- 명칭 상태: `Amarion / 아마리온`만 확인하며 법인 등록명은 `UNRESOLVED`다. 근거 없는 영문 법인명을 보충하지 않는다.
- 표식: 불가능 삼각 좌표와 어긋난 중심축 / `HISTORICAL RECONSTRUCTION`

### S.O.N — Severed Order Network / 단절명령망

- V6 역할: 기관·기업 통제에서 이탈한 사람과 경로의 느슨한 연합
- 지키는 것: 이동권, 비인가 기록, 탈주자 은닉망
- 버리는 것: 단일 책임과 장기 보호 의무
- 수단: 위조 신분, 분산 창고, 도청, 거래
- 대가 지불자: 보호망 말단과 정보가 팔린 피난민
- 승리의 실패: 통제에서 벗어난 세계가 강한 운송업자와 정보상에게 종속된다.
- V6 명칭 상태: `FIELD-ATTESTED NAME / V6 DRAFT` — 법인명보다 압수 장비와 통신에서 반복된 현장 공통명이며 A02 기준 명칭안으로 채택했다. `Syndicate`는 호출명, `Shadow Of Nemesis`는 구판 선전명으로 남긴다.
- 계보 금지: F.H.C와의 지원·운송·거래는 하위 지휘나 직접 계승을 뜻하지 않는다.
- 표식: 끊어진 통제환과 바깥으로 빠지는 세 경로 / `FIELD-ATTESTED DRAFT`

### P.O.H — Persons on Hold / 인계보류망

- V6 역할: 사람·오염물·장비를 공식망 밖에서 운송하고 인계
- 지키는 것: 거래 경로와 화물의 비밀
- 버리는 것: 화물이었던 사람의 이름과 이후 상태
- 수단: 빈 화물칸, 임시 구금소, 인계 코드
- 대가 지불자: 피난민, 납치자, 빚을 진 현장대
- 승리의 실패: 이동할 수 있는 모든 것이 가격표를 갖는다.
- V6 명칭 상태: `ANALYST-ASSIGNED NAME / V6 DRAFT` — 압수 송장의 `PERSONS ON HOLD` 코드에서 파생된 외부 분석명이며 자칭 법인명이 아니다. A02 기준 명칭안으로만 채택했다.
- 분리 원칙: `Power Of Haimun`은 논쟁적인 구판 풀이로 보존한다. 하이먼은 P.O.H 경로를 이용한 별도 세포일 수 있으나 P.O.H 전체와 같은 조직으로 확정하지 않는다.
- 표식: 빈 화물칸과 절취선 / `CRIMINAL STENCIL`

## 3. 현장 조직

### Ash Crew / 애시 크루

- V6 역할: 사건 뒤 시신·인식표·장비·잔류물 회수
- 지키는 것: 죽은 사람의 이름과 다음 작전의 증거
- 버리는 것: 생존 가능성이 낮은 현장 체류자
- 수단: 소각, 관계축 절단, 회수 태그, 마지막 통신 복원
- 대가 지불자: 회수대 자신과 신원 확인을 기다리는 유족
- 승리의 실패: 죽음을 더 잘 처리할수록 기관은 더 많은 전멸 작전을 승인한다.
- 구판 대조명: `리버스 사후 대응조직` / `LEGACY DESCRIPTOR`
- 표식: 인식표와 꺼지지 않은 잔불 / `FIELD PATCH`

### A.R.F — Asset Recovery Force / 자산회수대

- V6 역할: 비정합 핵, 장비, 인공체와 표본의 강제 회수
- 지키는 것: 봉쇄에 필요한 희귀 물자
- 버리는 것: 물자보다 회수 가치가 낮은 인원
- 수단: 삼점 고정, 견인, 격리 용기, 원격 폭파
- 대가 지불자: 견인대와 회수 경로 주민
- 승리의 실패: 살아 있는 사람도 회수물로 분류된다.
- V6 명칭·편제: `OFFICIAL SUBUNIT DRAFT` — 2005.01.21 애시 크루 산하. 구판 `Anomaly Recovery Force`는 역할 번역으로만 보존한다.
- 표식: 삼점 회수틀과 상부 견인점 / `OFFICIAL SUBUNIT DRAFT`

### C.P.D — Civilian Processing Division / 민간인 선별처리부

- V6 역할: 검문, 임시 대피, 가족·동행자 분리와 인계
- 지키는 것: 제한된 피난 정원과 오염되지 않은 이동열
- 버리는 것: 심사 시간을 초과한 사람, 관계축이 불명인 가족
- 수단: 열린 방패, 검문 게이트, 승인·격리·인계 분기
- 대가 지불자: 떨어져 나온 가족과 검문 인력
- 승리의 실패: 민간 보호가 합법적인 선별 포기의 이름이 된다.
- V6 명칭·편제: `OFFICIAL INTERNAL DRAFT` — 2005.01.21 애시 크루 산하. 대외 표지에는 같은 약어의 `Civilian Protection Division / 민간 보호부`를 사용한다.
- 선행 약어: 1989–2004년 C.P.D는 조직이 아니라 `Civilian Protection Directive / 민간 보호·분리 지침`으로 분류한다.
- 표식: 열린 방패와 세 분기 / `OFFICIAL INTERNAL DRAFT`

## 4. 교단 계통

이 절의 영문 병기는 분석 편의를 위한 번역이며 교단의 공식 자칭명으로 승격하지 않는다. 런타임 장부에서는 `ANALYST TRANSLATION`으로 표시한다.

### 우시노다 공통계통

- V6 역할: 타락·혈액·그림자 세 의식 계통을 묶는 역사적 호출명
- 지키는 것: 인간 기준상을 초월한다는 교리와 세 계통의 상호 호환성
- 버리는 것: 개인의 원래 몸, 이름과 관계
- 수단: 계약, 사도, 분산 교재, 영상 조작
- 대가 지불자: 신자, 의식 대상, 점령지 주민
- 승리의 실패: 단일 새 세계가 아니라 서로 양립하지 않는 세 구원이 충돌한다.
- 정사 상태: 종파 존재는 확정, 단일 중앙지휘는 미확정
- 표식: 빈 중심을 공유하는 세 획 / `RECONSTRUCTED`

### 타락교

- 주축: 형상 / 인식
- 교리: 인간의 고정된 몸과 자아는 불완전하며 계속 덮어써야 한다.
- 제공하는 것: 재생, 질병 억제, 변형 전투력
- 빼앗는 것: 원래 몸과 행동의 자율성
- 작전 방식: 침묵성 침윤, 융합성 변질, 생체 성장점
- 승리의 실패: 살아 있는 사람과 확산원의 차이가 사라진다.
- 표식: 비대칭 생체 가지와 성장점 / `FIELD RECONSTRUCTION`

### 혈교 중앙 계통

- 주축: 관계 / 형상
- 교리: 피는 생명 물질이 아니라 기억, 통로와 소유를 저장하는 그릇이다.
- 제공하는 것: 재생, 이동 경로, 전투 보급과 혈연 앵커
- 빼앗는 것: 몸의 소유권, 혈연과 타인의 기억
- 작전 방식: 혈액 저장소, 혈무, 피의 강 결계
- 승리의 실패: 모든 생명이 하나의 보급망으로 환원된다.
- 표식: 닫힌 혈액핵과 좌우 유입축 / `RECONSTRUCTED`

### 그림자교

- 주축: 인식 / 경로
- 교리: 관측되지 않은 빈자리가 진짜 통로다.
- 제공하는 것: 침투, 그림자 물질화, 정신·육체 잠입
- 빼앗는 것: 관측 가능성, 기억에서의 자리와 인격 경계
- 작전 방식: 어긋난 그림자, 분신, 이름 없는 이동
- 승리의 실패: 존재는 남아도 누구도 그 존재를 기억하거나 증명하지 못한다.
- 표식: 어긋난 이중 획과 끊긴 관측환 / `RECONSTRUCTED`

### 제1사도 분석 표상

제1사도는 독립 세력이 아니라 세 권능의 흔적을 함께 보이는 예외 개체다. 공식 휘장이 아니라 분석관이 만든 `ANALYST GLYPH`로 분리한다.

- 표식: 세 원의 중첩과 선행점
- 금지: 지도에서 세력 통제권처럼 사용, 교단 공식 문양으로 표기

- 제공하는 것: 해안 이동, 피난처, 전투 보급
- 빼앗는 것: 성채 자율성, 피난민의 몸과 충성
- 승리의 실패: 남부는 통일되지만 모든 마을이 하나의 전시 의식망이 된다.
- 표식: 뒤집힌 전시 왕관과 폐쇄 혈액핵 / `FIELD-ATTESTED DRAFT`

### 데드 존 혈교

- V6 역할: 북미 순례자와 중립 귀환자를 돕는 분리 계통
- 전략: 열린 이동로, 검문소 협상, 혈액 관계를 이용한 귀환 좌표 유지
- 중앙 혈교와의 관계: 2016년 이후 공개 결별, 실제 단절 정도 미확정
- 제공하는 것: 순례 호위와 귀환 앵커
- 빼앗는 것: 귀환자의 피, 관계 기록과 장기 채무
- 승리의 실패: 사람은 돌아오지만 누구의 소유로 돌아오는지 알 수 없게 된다.
- 표식: 열린 혈액 방울과 관통 순례로 / `FIELD-ATTESTED DRAFT`

## 6. 세력 관계의 기본 긴장

관계선은 다음 다섯 종류를 분리한다.

- `LINEAGE / COMMAND`: 아마리온→F.H.C, 애시 크루→A.R.F·C.P.D처럼 계보 또는 지휘가 확인된 관계
- `FORMER COMMAND / SPLIT`: N.H.C→애시 크루·레드울프와 레드울프 일부→S.O.N처럼 2005년 이탈 전후의 과거 지휘·합류 관계. S.O.N 전체가 레드울프의 후신이라는 뜻은 아니다.
- `COMPACT / COOPERATION`: 2001년 이후 U.A.C↔N.H.C·S.I.D처럼 상급·하급이 아닌 협약 관계
- `TRANSACTION / BROKERAGE`: F.H.C↔S.O.N·P.O.H, 우시노다↔P.O.H처럼 거래만 확인된 관계
- `DISPUTED ROUTE USE`: P.O.H···하이먼처럼 같은 운송로 사용 여부만 남고 조직 동일성은 확인되지 않은 관계

1984–1986년 `N.H.C 초기 표기`와 1993년 `N.H.C 비선형 위난사령부` 사이에는 같은 약어가 남았다는 사실만 확인된다. 초기 표기의 성격과 후대 조직의 직접 연속성은 모두 `DISPUTED`이며 화면에서도 비방향 점선으로 표시한다.

- U.A.C는 경로를 공유하고 책임을 분산한다.
- N.H.C는 시간을 벌기 위해 사람과 땅을 소모한다.
- S.I.D는 내부 침투를 막기 위해 시민의 기억을 감시한다.
- F.H.C는 붕괴를 상품과 규격으로 바꾼다.
- 이탈망은 자유를 제공하지만 보호 의무를 보장하지 않는다.
- 현장조직은 사람을 구하지만 다음 작전을 가능하게 만드는 증거도 회수한다.
- 교단은 기관이 포기한 사람을 받아들이지만 그 사람의 몸과 이름을 다른 질서에 편입한다.

어느 세력에도 세계를 원래대로 복구할 계획은 없다. 있다고 주장하는 세력은 대개 `원래 세계`의 정의를 독점하려 한다.
