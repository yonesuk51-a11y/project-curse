# Project Curse V6 정사·기록 규칙

문서 상태: `DRAFT / EDITORIAL CONSTITUTION`

## 1. 정사의 기본 구조

V6 정사는 하나의 전지적 설명문이 아니다. 서로 다른 기관·교단·성채·생존자가 남긴 기록을 비교하는 구조다. 그렇다고 모든 사실을 모호하게 만들지는 않는다.

각 사건은 반드시 다음 세 층을 분리한다.

1. `고정 사실` — 출동자, 시간, 회수물, 마지막 송신, 확인된 손실
2. `당시 해석` — 해당 기록 작성자가 원인과 의도를 어떻게 판단했는가
3. `현재 미해결` — 원인·책임·형이상학적 정체 중 아직 판정할 수 없는 것

사건 하나당 최소 하나의 고정 사실을 둔다. 모든 문장이 `알 수 없음`으로 끝나면 추리할 바닥이 사라진다.

## 2. 증거 등급

| 등급 | 의미 | 사용 예 |
|---|---|---|
| `CONFIRMED` | 독립 기록과 물증이 일치 | 공식 창설일, 회수물 일련번호 |
| `CORROBORATED` | 서로 다른 둘 이상의 기록이 핵심을 공유 | 전선 이동, 복수 검문소의 같은 호출명 |
| `OBSERVED` | 현장 장비 또는 직접 관측에 남음 | 사진, I.P.D 신호, 폐쇄 구역 측정값 |
| `TESTIMONY` | 증언은 있으나 독립 검증 없음 | 귀환자 기억, 교단 내부 진술 |
| `DISPUTED` | 자료가 서로 충돌 | 사건 날짜, 지휘권, 인물 동일성 |
| `ESTIMATED` | 불완전한 자료에서 산출 | 대흑림 거리, 전선 사상자 |
| `RECONSTRUCTED` | 후대 분석 또는 연출을 위해 재배열 | V6 4막 사건 재구성 |
| `UNRESOLVED` | 판정을 의도적으로 보류 | 신의 정체, 교단 중앙지휘 |

발생, 원인, 책임, 결과에 등급을 따로 붙인다. 사건 하나에 등급 하나를 붙여 모든 주장을 함께 확정하지 않는다.

## 3. 무결성·출처·제시 방식

모든 기록 화면은 다음 세 축을 구분한다.

| 축 | 질문 | 예시 |
|---|---|---|
| `TEXT INTEGRITY` | 현재 문장이 보호 원문과 같은가 | 보호 원문 무변경 |
| `SOURCE PROVENANCE` | 문서·이미지·음향의 계보와 권리를 검증했는가 | 출처 대조 대기 |
| `PRESENTATION` | 지금 보는 화면이 어떤 계층인가 | 보호 원문 / 분석 / 재구성 |

파일이 변형되지 않았다고 해서 세계 안에서 진실인 것은 아니다. 출처가 불명이라고 해서 파일을 지워도 되는 것도 아니다.

## 4. 보호 기록

`Cults_871104`와 `Immortality_860201`은 V6가 덮어쓰지 않는 보호 소스다.

- 원문 문장, 순서, 이미지 경로를 V6 해설 때문에 수정하지 않는다.
- V6 분석과 연출은 원문 밖의 별도 계층에 둔다.
- 재구성 장면은 원문 기록면 또는 시간값을 `sourceRef`로 가리킨다.
- 원문과 충돌하는 기존 연출 문장은 `LEGACY STAGING CLAIM`으로 분리한다.
- `ORIGINAL RECORD`라는 표현은 출처 계보가 검증됐을 때만 사용한다.
- 보호 원문 연결 오디오·영상은 권리 검토 전 자동 재생하지 않는다.

## 5. 실제 역사와 가상사의 경계

### 5.1 실제 책임을 바꾸지 않는다

실제 테러, 전쟁, 재난의 실행 주체, 피해와 사회적 책임을 가상 교단이나 괴이로 대체하지 않는다. 가상 사건은 같은 시대의 별도 비공개 사건일 수 있으나 `사실은 초자연 세력이 배후였다`는 반전을 사용하지 않는다.

### 5.2 관계 등급

실제 사건과 가상 사건의 관계는 아래 세 단계만 사용한다.

- `ADJACENT` — 같은 시대·장소에서 별도로 발생
- `EXPLOITED` — 가상 세력이 실제 혼란이나 제도 변화를 이용
- `AFTERMATH` — 실제 사건 이후 변한 사회·보안 환경의 영향을 받음

시간이 겹친다는 이유로 `CAUSED`를 사용하지 않는다.

### 5.3 문서 필드

실제 역사와 나란히 쓰는 사건은 다음 필드를 갖는다.

```text
PUBLIC FACT
PUBLIC SOURCES
FICTIONAL PARALLEL
RELATION STATUS
LATER ANALYSIS
RECORD LIMIT
```

공개 사실과 가상 병행사를 같은 문단에서 섞지 않는다.

### 5.4 분기점

- 1975–2005: 공개 거시사는 대체로 실제 세계와 병행하며 가상 사건은 비공개 층에서 움직인다.
- 2006: 북미 연속성 붕괴가 시작되는 명시적 분기점이다.
- 2007 이후: Project Curse 고유 대체 연표임을 화면에 표시한다.

## 6. 인물 정사 규칙

- 레거시 명부의 이름·소속·능력·사망 표기는 `LEGACY ROSTER SOURCE`로 보존한다.
- 후대에 보완한 생일·나이·국적·성격·경력은 `SUPPLEMENTAL DRAFT`로 분리한다.
- V6에서 승인한 정보만 `V6 CANON`으로 표시한다.
- 프레이 중심의 관계는 자동으로 세계 정사 중심축이 되지 않는다.
- 동일 이름이 여러 세력에 나타나면 먼저 동명이인 가능성을 기록한다.
- 이름을 바꿀 때 이전 이름을 별칭으로 남겨 자료 계보를 잃지 않는다.

## 7. 고사망률 집필 규칙

### 허용

- 작전 목표와 인물의 생존이 충돌한다.
- 구조팀이 비용·오염·지휘 문제 때문에 투입되지 않는다.
- 능력 사용으로 살아남았지만 기억이나 관계를 잃는다.
- 승리한 세력이 더 잔혹한 질서를 만든다.
- 선한 선택이 실패해도 선택의 의미는 기록에 남는다.

### 금지

- 주요 인물이라 총알, 오염, 의식 조건을 반복해서 우연히 피한다.
- 갑작스러운 죽음만으로 어두운 분위기를 대신한다.
- 매 사건이 전멸로 끝나 손실의 차이를 지운다.
- 고문과 신체 훼손을 설정의 깊이처럼 과시한다.
- 죽은 인물을 필요할 때마다 완전한 상태로 되돌린다.

사망은 `누가 죽는가`만큼 `누가 철수를 막았고, 무엇을 먼저 회수했으며, 기록에 어떤 말로 숨겼는가`를 보여줘야 한다.

## 8. 능력과 부활 판정

- 모든 능력은 매개, 조건, 거리·지속, 고정 대가, 과사용 징후와 대응법을 갖는다.
- 재생은 과거 형상을 현재에 덮어쓰는 행위이며 기억·인격·시간을 자동 복구하지 않는다.
- 부활 또는 귀환 인물은 몸, 기억, 이름, 관계와 시간의 동일성을 각각 판정한다.
- 인격 동일성이 확인되지 않은 귀환자를 원래 인물로 단정하지 않는다.
- 강한 의지 하나로 계약과 오염을 무시하지 않는다.

## 9. 지역과 문화

- 대흑림을 남아메리카의 원시적 신비로 묘사하지 않는다.
- 붕괴 전 현대 도시, 산업, 대학, 군과 통신망의 흔적을 남긴다.
- 실제 원주민 신앙을 가상 사교의 기원으로 사용하지 않는다.
- 현지 주민은 외부 기관의 피해자나 길잡이만이 아니라 법, 교역, 사냥과 기술의 주체다.
- 데드 존의 고대 왕국은 실제 북미 원주민 역사를 대체하지 않는 별도 중첩층으로 명시한다.

## 10. 편집 체크리스트

새 사건을 공개하기 전에 다음을 확인한다.

- [ ] 고정 사실이 최소 하나 있는가
- [ ] 발생·원인·책임·결과의 등급이 분리됐는가
- [ ] 누가 무엇을 잃었는가
- [ ] 기관의 행정어가 손실을 어떻게 감추는가
- [ ] 능력의 조건과 대응법이 있는가
- [ ] 생환이 자동으로 성공 판정되지 않는가
- [ ] 실제 역사 책임을 가상사로 바꾸지 않았는가
- [ ] 원문·분석·재구성을 구분했는가
- [ ] 미확정 설정을 확정 어조로 쓰지 않았는가
- [ ] 후속 사건에 남는 잔류물이 있는가
