# Project Curse V6 현상·능력 체계

문서 상태: `DRAFT / SYSTEM FOUNDATION`

## 1. 핵심 원리

인간은 현실을 직접 바꾸지 않는다. 사람, 장소와 사물이 자기 자신으로 남기 위해 반복하는 `기준상`을 붙들거나 다른 기준상으로 덮어쓴다. 둘 이상의 기준상이 같은 자리에서 동시에 성립하려 할 때 `비정합`이 발생한다.

초자연 능력, 기관 장비, 교단 의식과 저주 물건은 모두 이 충돌에 접근하는 서로 다른 기술이다.

## 2. 핵심 용어

| 용어 | V6 정의 |
|---|---|
| 기준상 / Reference State | 대상이 자기 자신으로 유지되기 위해 반복하는 상태 |
| 비정합 / Incongruity | 양립할 수 없는 기준상들이 동시에 성립하려는 현상 |
| 리버스 / Rebirth | 끝난 상태가 다른 순서·형상으로 다시 나타나는 사건 또는 과정 |
| 잔류장 / Residual Field | 사건 뒤 사라지지 않고 조건을 반복시키는 국지 환경 |
| 앵커 / Anchor | 하나의 기준상을 반복 유지하는 매개 |
| 생기 / Vital Assertion | 생명체가 자기 기준상을 유지하거나 주변에 강요하는 힘 |
| 타락 / Corruption | 대상의 기준상이 다른 형상에 의해 지속적으로 덮어써지는 과정 |
| 괴이 / Feral | 인간 기준상과 다른 상태로 안정된 비인간 개체 |
| 상위 존재 | 여러 사건에서 동일한 의도처럼 반복되는 패턴에 붙인 작전 명칭 |

`리버스`는 에너지나 종족의 이름으로 쓰지 않는다. `타락`은 교단이나 혈통이 아니라 변화 과정이다. `괴이`는 그 과정과 무관하게 비인간 기준상으로 안정된 개체까지 포함한다.

## 3. 현실의 다섯 축

| 축 | 바뀌는 것 | 전투·현상 예시 |
|---|---|---|
| 경로 | 위치, 거리, 방향, 통행 | 대흑림, 공간 이동, 염동력, 뒤틀린 도로 |
| 순서 | 시간, 노화, 사건 순서, 인과 | 예지, 가속, 귀환자의 시간 불일치 |
| 형상 | 몸, 생체 구조, 물질 형태 | 재생, 괴력, 신체 변형, 오토마톤 |
| 인식 | 기억, 인격, 관측 가능성 | 그림자 이동, 빙의, 투시, 최면 |
| 관계 | 이름, 혈연, 소속, 소유, 피 | 혈술, 계약, 모방, 저주 무기, 소환 |

능력 하나는 주축 하나와 보조축 하나를 원칙으로 한다. 세 축 이상을 안정적으로 다루는 인물은 예외이자 재난으로 취급하고, 그 이유와 대가를 사건으로 증명해야 한다.

## 4. 능력 획득의 네 경로

### A. 선천 공명형

- 특정 축의 비정합을 태어날 때부터 감지하거나 조절한다.
- 범위가 좁고 반복성이 높다.
- 오탐, 감각 과부하와 가족 단위 추적이 대가다.
- 혈연 유전처럼 보여도 실제 유전인지 확정하지 않는다.

### B. 의식 계약형

- 존재, 성물, 교리와의 계약을 몸에 각인한다.
- 강력하지만 발동 조건과 지급 대가가 명확하다.
- 교단에서 이탈해도 각인이 사라지지 않는다.
- 계약 위반은 능력 상실보다 인격·관계의 재작성으로 돌아올 수 있다.

### C. 오염 적응형

- 리버스나 타락에 노출된 뒤 인간 기준상을 불완전하게 유지한 생존자다.
- 두 상태를 오가므로 강하지만 어느 쪽이 원본인지 점점 불분명해진다.
- 침묵성 타락과 융합성 타락은 서로 다른 실패 또는 안정 형태다.
- 구조 후에도 시민권과 인물 동일성을 보장받지 못한다.

### D. 인공 접속형

- 장치, 이식물, 약물, 부적 규격으로 특정 축에 접속한다.
- 군사 표준화가 쉽지만 장비·보급·정비에 의존한다.
- 역류가 시작되면 장비를 벗어도 접속이 끝나지 않을 수 있다.
- 기관은 폐기 장비보다 접속자를 먼저 봉쇄할 수 있다.

한 인물은 주 획득 경로 하나와 보조 경로 하나까지만 가진다. 다수 계통을 무제한으로 겹치지 않는다.

## 5. 능력 문서의 필수 필드

모든 능력은 다음 항목을 갖는다.

1. 획득 경로
2. 주축과 보조축
3. 발동 매개
4. 발동 조건
5. 거리와 지속 시간
6. 고정 대가
7. 과사용 징후
8. 대응 방법

추가로 `사용 후 남는 잔류물`과 `다른 사람에게 전가되는 손실`을 기록한다.

## 6. 공통 전투 법칙

- 연결 없이 대상을 마음대로 바꾸지 못한다. 시선, 피, 이름, 그림자, 접촉, 표식 또는 장치가 필요하다.
- 큰 변화일수록 더 많은 앵커, 더 큰 대가와 더 긴 준비가 필요하다.
- 일반 병력도 매개 절단, 시야 차단, 시계 분리, 이름표 교체와 표식 파괴로 능력자를 제압할 수 있다.
- 재생은 죽음을 무효화하지 않는다. 어떤 과거 형상을 복원할지 선택할 뿐이다.
- 기술은 현상을 제거하지 않는다. 측정, 지연, 경로 분리와 국지 고정을 수행한다.
- 의식은 원시 기술이 아니다. 이름, 희생과 공동 기억을 매개로 쓰는 다른 공학이다.
- 한 번 알려진 대응법은 완전한 해답이 아니다. 능력자도 매개와 조건을 바꿀 수 있지만 그만큼 대가가 커진다.

## 7. 대가의 네 계정

능력의 대가는 추상적인 피로로 끝나지 않는다.

### 수명

- 노화, 장기 손상, 회복 한계가 누적된다.
- 치료는 손상을 지연할 수 있어도 이미 소모한 시간을 되돌리지 않는다.

### 기억

- 사건, 사람, 기술 또는 자기 이름의 일부가 사라진다.
- 잃은 기억을 문서로 다시 배워도 관계축의 동일성은 복구되지 않을 수 있다.

### 신체

- 변형, 감각 소실, 이식물 의존과 비인간 조직의 성장이 남는다.
- 겉모습이 복구돼도 내부 기준상은 바뀔 수 있다.

### 관계

- 가족, 계약, 소유, 지휘권과 사회적 신원이 다른 대상에게 옮겨 간다.
- 가장 위험한 능력은 사용자가 죽는 것이 아니라 주변 사람들이 사용자를 기억하지 못하게 만든다.

## 8. 타락 단계

| 단계 | 상태 | 현장 판정 |
|---|---|---|
| `C0 노출` | 잔류장 접촉, 물증 없음 | 관찰·장비 격리 |
| `C1 공명` | 반복 감각, 꿈, 미세 생체 변화 | 출입 제한·동행자 대조 |
| `C2 침윤` | 행동·언어 반복, 조직 변화 | 시민권 보류·매개 탐색 |
| `C3 분기` | 인간 기준상과 다른 상태가 교대 | 무장 격리·이름/시간 앵커 유지 |
| `C4 안정 변질` | 비인간 기준상으로 자립 | 타락체 작전 분류 |
| `C5 확산원` | 주변 대상의 기준상을 능동 재작성 | 지역 봉쇄·회수보다 경로 단절 우선 |

단계가 높다고 지능이 낮아지는 것은 아니다. 일부 C4·C5 개체는 인간보다 더 정교하게 협상하고 보급망을 이용한다.

## 9. 개체 분류

- `괴이`: 비인간 기준상으로 안정된 개체
- `타락체`: 인간·동물·괴이가 타락 과정을 거친 결과
- `타락 야생체`: 이미 괴이인 생물이 두 번째 덮어쓰기를 겪은 개체
- `상위체`: 종명이 아니라 지능·통솔·현상 조작 능력에 따른 작전 등급
- `인공체`: 기관·기업·교단이 의도적으로 조립하거나 봉인한 개체

교단은 현상의 창조주가 아니라 특정 사용법을 독점하려는 집단이다. 모든 혈액 능력자가 혈교 신자도 아니며, 모든 타락체가 타락교의 결과도 아니다.

## 10. 예시 능력

### 태양의 생기

- 획득: 선천 공명 또는 인공 증폭
- 축: 형상 / 관계
- 매개: 사용자의 시야와 심박 동기
- 효과: 아군의 손상 인지를 지연하고 생체 리듬을 강제 정렬
- 대가: 사용자가 노화와 장기 손상을 대신 떠안음
- 과사용: 피부 탄화, 심박 비동기, 아군 손상의 역류
- 대응: 시야 차단, 독립 심박 교란, 장기전

### 혈액 재생

- 획득: 의식 계약
- 축: 형상 / 관계
- 매개: 자기 피 또는 사전에 연결된 혈액
- 효과: 등록된 과거 형상을 현재에 덮어씀
- 대가: 기억·감각·나이가 완전히 돌아오지 않음
- 과사용: 타인의 조직과 기억이 섞임
- 대응: 혈류 경로 분리, 고열, 관계 앵커 파기

### 예지

- 획득: 선천 공명 또는 오염 적응
- 축: 순서 / 인식
- 매개: 현재 사건과 연결된 물건 또는 사람
- 효과: 하나의 미래가 아니라 가능한 사건 순서들을 병렬 관측
- 대가: 현재 기억이 가능성 중 하나로 밀려남
- 과사용: 사용자가 실행하지 않은 선택을 자기 과거로 기억함
- 대응: 거짓 정보, 다중 작전, 매개 분산

## 11. 끝까지 설명하지 않는 것

- 기준상의 형이상학적 기원
- 신과 상위 존재의 진짜 정체
- 아마리온 실험과 최초 현상 사이의 직접 인과
- 데드 존이 귀환자를 선별하는 기준

그러나 `무엇을 연결해야 발동했는가`, `누가 철수를 막았는가`, `어떤 대가가 남았는가`는 설명한다. V6의 원칙은 `우주론은 불명, 현장 규칙은 명확`이다.
