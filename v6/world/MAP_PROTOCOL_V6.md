# Project Curse V6 증거 지도 규약

문서 상태: `MAP A01 / EVIDENCE CARTOGRAPHY / NON-NAVIGATIONAL`

## 1. 지도 역할

V6 지도는 실제로 이동할 수 있는 지리 서비스가 아니다. 기관이 어느 지역을 관측했고, 무엇을 잃었으며, 어떤 주장이 서로 충돌하는지를 보여 주는 증거 도면이다.

`#/map`은 두 모드만 제공한다.

1. `WORLD ATLAS / 세계 상황도` — 일본 계측권, 데드 존, 대흑림, 유럽 검열권, 북부전선과 남부 동원권을 비교한다.
2. `EVIDENCE COPY / 사건·작전 증거 사본` — 실제 지리 대신 기록에 남은 시간·지휘·신호·손실 순서를 재구성한다. 작전, 동시성 관측, 전선 분석, 적대 문서와 귀환 증언을 같은 분류로 오인하지 않도록 사본별 표시명을 둔다.

구판의 지역 지도, 세부 지역, 작전 시나리오, 사용자 판정, 결말 저장을 하나의 공통 지도에 합치지 않는다. 사용자의 선택 결과는 `LOCAL SCENARIO STATE`일 수 있으나 V6 공통 정사를 바꾸지 않는다.

## 2. 좌표 원칙

지도 내부의 `position.plot.x / y`는 CSS 도면 위에 기호를 놓기 위한 `DISPLAY PLOT` 값이다. 모든 현재 전구·신호는 `position.geo:null`과 `navigation:'PROHIBITED'`를 함께 가진다.

- 위도·경도가 아니다.
- 거리·방위·도착 시간을 계산할 수 없다.
- 안전 경로나 실제 국경을 나타내지 않는다.
- 검열된 장소를 공개 좌표로 복원하지 않는다.
- 대흑림 내부의 배열은 물리적인 인접 순서를 보증하지 않는다.

실제 위치가 검증된 경우에만 별도의 `geo` 계층을 둘 수 있다. 검열·추정·상충 상태에서는 `geo:null`을 유지한다. 구판에서 사용한 `[9.2, 55.5]`는 보호 원문이 뒷받침하지 않는 `LEGACY LOCATION CLAIM / DISPUTED`이므로 V6 런타임 지도 좌표로 이관하지 않는다.

화면에는 항상 다음 경고를 노출한다.

```text
EVIDENCE PLATE / 비항법 도면
PLOT COORDINATES ONLY
DISTANCE · BEARING · ETA INVALID
```

## 3. 증거 계층

하나의 `confidence` 점수로 사건 전체를 확정하지 않는다. 필요한 경우 다음 축을 따로 판정한다.

| 축 | 질문 |
|---|---|
| `occurrence` | 사건 발생 자체가 기록되었는가 |
| `time` | 날짜·시각·시간대가 일치하는가 |
| `location` | 실제 장소와 범위가 확인되었는가 |
| `cause` | 원인 또는 행위 주체가 확인되었는가 |
| `relation` | 다른 사건·세력과의 관계가 확인되었는가 |
| `outcome` | 구조·생환·사망·회수 결과가 기록되었는가 |

현재 런타임의 모든 15개 신호와 5개 증거 사본은 이 여섯 축의 `claims`를 가진다. 시각 상태는 색상만으로 구분하지 않는다. 중심 표식은 발생 근거, 외곽틀은 위치 판정을 우선 표시하며 상세 패널은 여섯 축을 모두 문자로 제공한다.

| 상태 | 형태 |
|---|---|
| `OBSERVED` | 실선 표식 |
| `CORROBORATED` | 이중 외곽선 |
| `CLAIMED / TESTIMONY` | 점선 중심 또는 빈 마름모와 문자 라벨 |
| `DISPUTED / MIXED` | 어긋난 이중 외곽틀 |
| `ESTIMATED` | 회전한 외곽 사각틀 |
| `REDACTED` | 점선 사각틀과 사선 |
| `RECONSTRUCTED` | 문자 라벨과 분석 프레임 |
| `UNRESOLVED` | 관계선 없이 판정 보류 라벨 |

## 4. 1986년 피의 호수

보호 원문은 장소를 `독일 본토 [검열] 지역`이라고만 기록한다. `독일·덴마크 사이 북해권` 또는 구판의 정밀 좌표를 보호 원문의 확정 정보처럼 사용하지 않는다.

날짜도 하나로 합치지 않는다.

- `1986.02.01` — 보호 기록 식별과 V6 현장 사건 등록
- `1986.07.25` — 구판 사건철의 회수·재진입·공식 등록 주장

두 날짜의 정확한 관계가 확정될 때까지 `/`, `DISPUTED TIME`, 또는 사건·등록 분리 가설을 함께 표시한다.

`OP-IMMORTALITY` 작전 사본은 보호 원문에 직접 남은 시각을 네 구간으로 묶는다.

1. `16:10–16:46` 투입과 전진 — 16:27 기록 포함
2. `17:02–17:58` 텐트와 혈액성 수역
3. `18:06–18:42` 예거트 이상, 유닛4 통신 두절, 밀로 추적 신호 충돌
4. `18:44–19:00` 마지막 통신과 완료 판정

마지막 상태는 `전원 사망`으로 쓰지 않는다.

```text
SYSTEM STATUS / COMPLETE
HUMAN RETURN / NONE CONFIRMED IN RECORD
RESCUE DEPLOYMENT / NO RECORD LOCATED
FINAL OUTCOME / UNRESOLVED
```

## 5. 삼야 무응답

현재 V6 시간창은 다음과 같다.

```text
2042.10.28–10.31
61H 01M
TIMEZONE RECONCILIATION / UNRESOLVED
```

대흑림 성채 여섯 곳과 데드 존 검문소 네 곳은 같은 시간대의 독립 관측점이다.

- 열 점 사이에 물리 경로를 그리지 않는다.
- 대서양을 가로지르는 연결선을 그리지 않는다.
- 포털·동일 주체·공통 심층 구조를 자동 확정하지 않는다.
- 화면상 배열은 실제 거리와 인접성을 뜻하지 않는다.
- 호출명이 대응해도 자동으로 관측점을 짝짓지 않는다.

화면에는 항상 `TEMPORAL CORRELATION ONLY / NO ROUTE`를 표시한다.

## 6. 세계 상황도 레이어

초기 레이어는 다음 여섯 개로 제한한다.

| 레이어 | 기본값 | 내용 |
|---|---|---|
| 전구 | 켜짐 | 여섯 관측·통제 권역 |
| 사건 | 켜짐 | 보호 기록과 직접 연결된 사건 |
| 2042 동시성 | 켜짐 | 삼야 무응답의 독립 관측점 |
| 증언·주장 | 켜짐 | 귀환자 증언과 적대 세력 정보 |
| 관계선 | 꺼짐 | 관측·증언을 대조하는 비지리적 관계선 |
| 세력 표식 | 켜짐 | 사건과 직접 관련된 `map` 문맥 마크 |

관계선은 안전 경로가 아니며 기본값을 꺼 둔다. 삼야 무응답의 두 관측 군집은 관계선 레이어에도 연결하지 않는다.

관계선 레이어를 켜면 선만 노출하지 않고 관계 대장을 함께 표시한다. 대장은 각 선의 근거, `실제 이동 경로 아님` 경고와 실행 미확정 여부를 문자로 제공한다.

## 7. 사건·작전 증거 사본

현재 증거 사본은 다섯 기록 묶음을 제공한다. 공통 제목 아래에서도 자료 성격과 손실 판정 라벨을 따로 둔다.

| ID | 화면 분류 | 손실 판정 | 지도에서 확정하지 않는 것 |
|---|---|---|---|
| `immortality` | `OPERATION COPY` | `RECORD GAP` | 실제 위치·구조 결과 |
| `three-night` | `SYNCHRONY EVIDENCE COPY` | `RECOVERY STATUS` | 물리 연결·단일 원인 |
| `sixth-line` | `FRONTLINE ANALYSIS COPY` | `OPERATING COST / RECONSTRUCTED` | 영토 회복·민간 생환 |
| `broken-crown` | `HOSTILE DOCUMENT RECONSTRUCTION` | `CLAIMED OBJECTIVE / PROJECTED LOSS` | 계획 존재·규모·지휘권 |
| `deadzone-return` | `TESTIMONY COMPARISON` | `RETURN COST / TESTIMONY` | 실제 순례길·귀환자 동일성 |

작전 단계 사이의 길이와 각도는 실제 거리와 방향을 뜻하지 않는다. V6는 해당 기록의 결과를 사용자가 바꾸는 게임 상태를 저장하지 않는다.

## 8. 국소 증거 도면

다섯 증거 사본은 공통 세계 상황도와 별개로 `LOCAL EVIDENCE SCHEMATIC`을 제공한다. 이 도면의 표식은 실제 HTML 버튼이며, 선택하면 대응하는 기록 단계가 열린다. 모든 국소 도면 역시 `coordinateType:'DISPLAY_PLOT'`, `geo:null`, `navigation:'PROHIBITED'`를 유지한다.

| 사본 | 도면 문법 | 선의 의미 | 금지되는 해석 |
|---|---|---|---|
| 피의 호수 | 보호 원문 기록 순서 | 시각이 기록된 순서 | 실제 경로·거리·방향 |
| 삼야 무응답 | 대흑림 6점·데드 존 4점의 분리 군집 | 선 없음 | 대륙 연결·포털·공통 원인 |
| 제6차 차단선 | 기관별 작동 분석 사슬 | 계측·차단·봉쇄·철수의 분석 순서 | 실제 전선 위치·영토 회복 |
| 남부 동원 문서 | 적대 문서 주장 사슬 | 문서가 주장하는 실행 논리 | 실행 확인·지휘권 확정 |
| 데드 존 귀환 | 검문 장부·증언 대조 사슬 | 자료를 비교하는 순서 | 실제 순례길·안전 경로 |

피의 호수의 `16:10`, `17:02`, `17:41`, `18:06`, `18:42`, `18:44–19:00` 표식은 보호 원문에 남은 시간만 사용한다. 화면상 간격은 시각 차이까지 비례하지 않는다.

삼야 무응답은 영구적으로 `links:[]`를 유지한다. 두 관측 군집 사이에는 `NO LINK / NO ROUTE / NO COMMON CAUSE` 경계가 놓이며, 호출명이나 화면상 위치가 비슷해도 점끼리 자동 대응시키지 않는다.

남부 동원 도면의 선은 `HOSTILE CLAIM`으로 표시하고 실선 작전 경로처럼 그리지 않는다. “계획 문서가 그렇게 주장한다”와 “그 계획이 실행되었다”를 항상 분리한다.

작은 화면에서는 도면 자체를 760px 폭으로 유지해 형태를 찌그러뜨리지 않고 가로 스크롤 영역으로 제공한다. 도면 밖의 단계 버튼과 읽기 패널에도 같은 정보를 남겨 지도 제스처 없이 열람할 수 있게 한다.

## 9. 세력 표식

지도는 `FACTION_MARKS`의 `map` 문맥만 사용한다.

- 시각 크기는 16–20px을 기준으로 한다.
- 실제 버튼의 터치 영역은 최소 44×44px이다.
- 표식 옆 또는 상세 패널에 전체 한국어 명칭을 제공한다.
- 공식·현장 확인·감식 재구성·분석 기호 상태를 색상 외의 프레임으로 표시한다.
- 제1사도 분석 기호를 세력 통제권처럼 사용하지 않는다.
- 여러 세력이 겹치면 중심 표식을 축소하지 않고 상세 패널에서 나열한다.

## 10. 접근성·모바일

- 모든 지도 마커는 실제 HTML `button`이다.
- 같은 정보는 전구 카드, 15개 접촉 목록과 증거 사본 목록으로도 접근할 수 있다.
- 레이어 제어는 `aria-pressed`를 사용한다.
- 선택 변경은 짧은 `aria-live` 상태로 알린다.
- 툴팁에만 정보를 두지 않는다.
- `Esc`는 세계 상황도의 선택만 해제한다.
- 작은 화면에서 도면은 가로 스크롤할 수 있지만, 모든 핵심 정보는 아래 목록과 상세 패널에도 존재한다.
- 작전 단계는 지도 제스처 없이 이전·다음 버튼과 단계 버튼으로 조작한다.
- 모션 감소 환경에서는 지도 진입·표식 강조 애니메이션을 제거한다.
- 자동 음향, 자동 영상, 지속적인 레이더 펄스는 사용하지 않는다.

## 11. 이관 금지

다음 구판 상태는 V6 공통 지도에 직접 이관하지 않는다.

- 사용자 시나리오의 판정과 결말
- 브라우저 로컬 저장으로 열린 작전 상태
- 검증되지 않은 위경도
- `피의 호수`라는 이름만 같은 별도 수역의 자동 병합
- 지역 탭과 작전 탭의 단일 `confidence` 점수
- F.H.C·교단·범죄망의 거래선을 지휘 계보로 바꾸는 해석

V6 지도는 세계를 완성된 하나의 진실로 합치지 않는다. 지도가 선명해질수록, 무엇이 검열되었고 무엇이 끝내 확인되지 않았는지도 함께 선명해져야 한다.
