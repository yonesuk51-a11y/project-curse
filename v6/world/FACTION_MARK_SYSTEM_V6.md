# Project Curse V6 세력 표식 체계

문서 상태: `CONTEXT STUDY A02 / 17 SYSTEMS / 51 VARIANTS / NOT FINAL EMBLEMS`

## 1. 이번 리메이크의 목표

구판 표식은 조직별 출처·사용처·신뢰도라는 좋은 메타데이터를 갖고 있지만, 크기·선 두께·색상·복잡도가 제각각이고 공식 휘장과 감식 재구성이 같은 방식으로 보인다.

V6는 로고를 모두 같은 원 안에 넣는 방식이 아니라, 세력의 임무·금기·손실 방식을 하나의 중심 실루엣으로 압축한다.

현재 `/v6/#/marks`의 CSS 표식 17개는 정보 구조와 실루엣을 검증하기 위한 코드 기반 형태 연구다. A02부터 각 중심형을 `seal / badge / map` 세 문맥으로 동시에 제시하고, 공식·현장 확인·감식 재구성·분석 기호를 표식 바깥 프레임으로 구분한다. 최종 마스터는 정사 명칭과 교리가 승인된 뒤 별도 벡터 자산으로 제작한다.

## 1.1 A02 명칭 판정

| 약어 | V6 명칭안 | 명칭 계층 |
|---|---|---|
| U.A.C | Unified Anomaly Compact / 통합 이상현상 협약체 | 공식 명칭안 |
| N.H.C | Nonlinear Hazard Command / 비선형 위난사령부 | 공식 명칭안 |
| S.I.D | Signal Integrity Directorate / 신호무결성국 | 공식 명칭안 |
| F.H.C | Frontier Habitat Consortium / 개척거주권 컨소시엄 | 공식 명칭안 |
| S.O.N | Severed Order Network / 단절명령망 | A02 채택 현장명 / V6 초안 |
| P.O.H | Persons on Hold / 인계보류망 | A02 채택 분석관 지정명 / V6 초안 |
| A.R.F | Asset Recovery Force / 자산회수대 | 애시 크루 산하 공식 초안 |
| C.P.D | Civilian Processing Division / 민간인 선별처리부 | 애시 크루 산하 내부 공식 초안 |

약어가 조직보다 먼저 등장하는 경우에는 후대 조직의 창설일을 소급하지 않는다. 1984–1986년 N.H.C는 장비 규격·소규모 현장대 호출명·후대 편집 라벨 가설을 모두 `DISPUTED`로 유지하며, `Nonlinear Hazard Classification`은 분석상 임시 풀이일 뿐이다. 1989–2004년 C.P.D는 `Civilian Protection Directive` 현장 지침으로 분리한다.

명칭 상태와 표식 상태도 합치지 않는다. 예를 들어 S.O.N의 명칭은 복수 현장에서 확인됐지만 현재 중심 표식은 여전히 `FIELD-ATTESTED DRAFT`다. P.O.H의 표식은 압수 송장에서 확인된 범죄 스텐실이지만 `Persons on Hold`라는 풀네임은 분석관 지정명이다.

## 2. 마스터 규격

- 공통 좌표: `96 × 96`
- 안전 여백: 8유닛
- 기본 모듈: 4유닛
- 주선 두께: 4–5유닛
- 최소 내부 간격: 4유닛
- 심벌 내부 텍스트·약자 금지
- 그라데이션 금지
- 단색에서 핵심 실루엣 유지
- 밝은 배경, 어두운 배경과 흑백 역상 제공

하나의 마스터를 단순 축소하지 않고 세 변형을 별도로 만든다.

| 변형 | 크기 | 사용처 |
|---|---:|---|
| `seal` | 72–128px | 문서 인장, 세력 상세. 내부 형태와 상태 프레임 전체 표시 |
| `badge` | 28–40px | 목록, 관계망, 인물 소속. 제작 라벨과 미세 장식 제거 |
| `map` | 16–20px | 지도, 작전선, 군집 기호. 중심 실루엣과 외부 판정만 유지 |

## 3. 형태 계열

### 공식 기관

- 닫힌 기하학
- 좌우 균형
- 수직·수평 기준축
- 통제·절차·봉쇄를 표현

대상: U.A.C, N.H.C, S.I.D, F.H.C

### 외부·상업·분산 조직

- 열린 프레임
- 스텐실·절취선
- 연결과 이탈 방향

대상: Amarion, S.O.N, P.O.H

### 현장 조직

- 패치형 외곽
- 강한 이동 방향
- 회수구·통로·인식표

대상: Ash Crew, A.R.F, C.P.D

### 교단 계통

- 비대칭
- 유기적 가지와 빈 중심
- 같은 모티프의 오염·분기

대상: 우시노다, 타락교, 혈교, 그림자교, 남부 혈교, 데드 존 혈교

### 분석 기호

- 공식 휘장과 다른 이중 괄호 프레임
- 화면마다 `ANALYST GLYPH` 표시

대상: 제1사도

## 5. 공식 여부는 표식 밖에서 표시

문양 자체에 신뢰도와 정사 상태를 섞지 않는다. UI 프레임이 다음 상태를 표시한다.

| 상태 | UI 프레임 |
|---|---|
| `OFFICIAL` | 실선 사각 프레임 |
| `FIELD-ATTESTED` | 모서리가 잘린 프레임 |
| `RECONSTRUCTED` | 점선 괄호 |
| `ANALYST GLYPH` | 이중 대괄호 |
| `V6 DRAFT` | 우하단 제작 상태 라벨 |

이 규칙은 감식관이 복원한 교단 문양을 실제 교단이 승인한 휘장으로 오해하는 것을 막는다.

## 6. 지부·하위부대

모든 지부에 전혀 다른 로고를 만들지 않는다.

```text
부모 세력 마크
+ 외부 카르투슈
+ 지역·지부 코드
+ 기능 탭
```

- F.H.C-유니온과 F.H.C-아크는 F.H.C 중심형을 공유한다.
- N.H.C 현장대는 N.H.C 중심형에 부대번호와 기능 탭을 붙인다.
- 남부·데드 존 혈교는 혈액핵 모티프를 공유하되 폐쇄·개방 구조로 갈라진다.
- 직접 계승이 미확정이면 `파생 마크`가 아니라 `유사 표식`으로 표시한다.

## 7. 지도·문서·모바일 규칙

### 지도

- 16–20px 전용 단순 실루엣 사용
- 약자 대신 전체 명칭을 함께 표시
- 적대·동맹·미확정을 색상만으로 구분하지 않음
- 세력 중첩 시 개별 마크를 축소하지 않고 군집 기호 사용
- 낮은 줌에서는 세력 마크보다 통제 패턴을 우선

### 문서

- 공식 인장은 56–80px 실선 프레임
- 감식 재구성은 점선 프레임과 명시적 라벨
- 배경 워터마크가 본문 대비를 방해하지 않음
- 제1사도 분석 기호에는 항상 `공식 문양 아님` 표기

### 모바일

- 최소 시각 크기 28px
- 마크 옆 전체 세력명 필수
- 마크 단독 터치 금지
- 전체 터치 행 최소 높이 48px
- 관계망은 선택 세력과 인접 세력만 우선 표시
