# Project Curse 5.33.0

`Readable Settings & Session Health`는 설정을 조작하는 사람과 문제를 진단하는 사람에게 같은 양의 기술 정보를 강제로 보여 주지 않는다.

## 일반 상태

설정 패널 상단에는 현재 품질 정책을 한국어 상태 문장으로 표시한다. 사용자는 세부 지연시간을 읽지 않아도 사이트가 전체 품질인지, 균형 모드인지, 데이터 절약 중인지 바로 알 수 있다.

## 설정 구역

- 화면·전송: 전송 품질, 시각 효과, 텍스트 등장
- 음향: 인터페이스 음향, 환경음

## 고급 세션 진단

기본적으로 닫혀 있으며 문제가 있을 때만 펼친다.

- 연결: 유형, 지연시간, 기기 메모리, CPU 스레드
- 로딩: 부팅 노출, DOM 준비, 누적 전송량
- 이동: 마지막 채널 전환
- 세션: 실제 화면 표시 시간, 백그라운드 시간
- 런타임: 지원 브라우저의 JavaScript 힙 사용량

```js
ProjectCurseTelemetry.getSnapshot().session
ProjectCurseChannelIdentity.getDiagnostics()
```

모든 진단은 현재 브라우저 안에서만 계산하며 외부 서버로 전송하지 않는다.
