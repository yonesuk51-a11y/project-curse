# Project Curse 5.30 사용 메모

상단 메뉴에서 다섯 채널을 직접 선택한다. 작은 화면에서는 `현재 화면` 버튼을 눌러 세로 채널 패널을 연다.

`DISPLAY / FX`에서 다음 항목을 독립적으로 바꿀 수 있다.

- 시각 효과: `FULL`, `BALANCED`, `REDUCED`
- 인터페이스 음향: `FULL`, `MINIMAL`, `OFF`
- 환경음: `ON`, `OFF`
- 텍스트 등장: `ON`, `OFF`

`AUDIO LOCAL`은 세부 설정과 별개의 전체 음소거다. 인터페이스 음향을 꺼도 안전 경보 버스는 유지되며, 전체 소리를 즉시 끄려면 `AUDIO LOCAL`을 사용한다.

설정은 서버로 전송하지 않고 브라우저의 `project_curse_preferences_v1` 항목에 저장한다. 운영체제의 동작 줄이기가 활성화된 경우 화면에는 REDUCED가 우선 적용되지만 사용자가 선택한 효과 단계 자체는 바뀌지 않는다.
