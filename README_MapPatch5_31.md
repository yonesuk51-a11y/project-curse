# Project Curse 5.31 사용 메모

상단 채널 오른쪽 숫자는 정적인 장식이 아니다.

- 단말 상태: 현재 홈 수신 신호 수
- 상황 관제: 진행 중인 작전과 순례 수
- 세계 기록: 공통 사건망에 연결된 사건 수
- 정보 분석: 열람 가능한 세력 분석 파일 수
- 기록보관소: 읽지 않은 판정 문서가 있으면 읽지 않은 수, 없으면 공개 기록 수

`DISPLAY / FX`의 `현재 세션 진단`은 현재 브라우저 탭에서만 측정한 값이다. 서버로 전송하거나 다른 사용자와 공유하지 않는다.

환경음은 페이지를 열었다는 이유만으로 내려받지 않는다. 첫 클릭 또는 키 입력 뒤에 오디오가 허용되면 요청하고, 환경음 설정이 `OFF`이거나 전체 음소거 상태면 재생하지 않는다.
